# 语雀知识库下载器 - 使用指南

## 安装

双击运行 `语雀知识库下载器 Setup x.x.x.exe`，按提示选择安装目录，完成安装后桌面会生成快捷方式。

## 第一步：激活软件

首次打开软件会显示激活界面：

1. 界面上会自动显示你的**机器码**（每台电脑唯一）
2. 点击「复制」按钮，将机器码发送给管理员
3. 管理员会回复一串**授权码**
4. 将授权码粘贴到输入框，点击「激活」

激活成功后会自动进入主界面。授权信息会保存在本地，下次打开无需重复激活。

> 注意：授权码与电脑硬件绑定，更换电脑后需要重新获取授权码。

## 第二步：下载知识库

### 基本使用

1. 打开语雀，进入你要下载的知识库页面，复制浏览器地址栏的 URL
   - 格式类似：`https://www.yuque.com/用户名/知识库名`
2. 将 URL 粘贴到软件的「知识库 URL」输入框
3. 点击「选择目录」选择文件保存位置（默认保存到"文档/yuque-download"）
4. 点击「开始下载」

下载过程中可以在进度条和日志区域查看实时状态。完成后点击「打开目录」可直接在资源管理器中查看下载的文件。

### 下载私有知识库

如果知识库需要登录才能访问，需要填写 Token：

1. 在浏览器中登录语雀
2. 按 `F12` 打开开发者工具，切换到「应用」(Application) 标签
3. 左侧找到 Cookie → `https://www.yuque.com`
4. 找到名为 `_yuque_session` 的条目，复制它的值
5. 在软件中展开「🔐 认证设置」，将值粘贴到 Token 输入框

> 如果是企业版语雀，Cookie 名称可能不是 `_yuque_session`，请在 Cookie Key 中填写实际的名称。

### 高级选项说明

展开「⚙️ 高级选项」可以看到以下设置：

| 选项 | 说明 |
|------|------|
| 忽略图片 | 不下载文档中的图片，仅保留文字内容 |
| 忽略附件 | 不下载文档中的附件文件 |
| 生成文档 TOC | 在每篇文档中生成目录索引 |
| 增量下载 | 只下载新增或更新的文档，适合重复下载同一知识库 |
| 视频链接转 video 标签 | 将视频链接转为 HTML video 标签，方便本地播放 |
| 隐藏页脚信息 | 不在文档末尾添加更新时间和原文链接（默认开启） |

## 第三步：Web 预览（可选）

下载完成后，可以通过内置预览服务在浏览器中阅读知识库：

1. 切换到「🌐 预览」标签页
2. 点击「选择目录」，选择下载生成的知识库文件夹（包含 index.md 的目录）
3. 点击「启动预览」，浏览器会自动打开预览页面
4. 左侧为文件夹树形导航，点击文档名即可阅读，支持代码高亮
5. 使用完毕后点击「停止」关闭预览服务，或直接关闭软件会自动停止

> 预览服务运行在本地 18888 端口，仅本机可访问，不会暴露到网络。如果端口被占用会自动尝试下一个端口。

## 第四步：格式转换（可选）

下载完成后，可将 Markdown 文件批量转换为 PDF 或 Word 格式：

1. 切换到「🔄 转换」标签页
2. 选择输出格式：
   - **PDF**：排版精美，适合阅读和分享
   - **Word**（.doc）：可二次编辑
3. 点击「选择目录」，选择已下载的知识库文件夹（包含 .md 文件的目录）
4. 调整并发数：
   - PDF 建议 **2~4**（每个文件需要渲染窗口，占用较多内存）
   - Word 可设置 **5~10**（纯文件写入，速度较快）
5. 点击「开始转换」，等待完成
6. 完成后点击「打开输出目录」查看转换结果

> 转换后的文件会保存在知识库目录同级的 `xxx_pdf` 或 `xxx_word` 文件夹中，目录结构与原始文件保持一致。

## 下载结果

下载完成后，文件按照知识库原始目录结构保存：

```
下载目录/
├── 知识库名称/              ← Markdown 源文件
│   ├── index.md             ← 目录索引
│   ├── 文档标题1.md
│   ├── 文档标题2.md
│   ├── 子目录/
│   │   ├── 文档标题3.md
│   │   ├── 更深的子目录/
│   │   │   └── 文档标题4.md
│   │   └── ...
│   └── ...
├── 知识库名称_pdf/          ← PDF 转换结果（转换后生成）
│   ├── 文档标题1.pdf
│   └── ...
└── 知识库名称_word/         ← Word 转换结果（转换后生成）
    ├── 文档标题1.doc
    └── ...
```

所有 Markdown 文档均为标准格式，可以用任意 Markdown 编辑器打开阅读。

## 授权说明

软件采用授权码激活机制，激活成功后 Tab 栏右侧会显示当前授权状态：

| 状态 | 说明 |
|------|------|
| ✅ 永久有效 | 永久授权，无需续期 |
| ✅ 具体日期时间 | 有期限授权，显示到期时间 |
| ⚠️ 已过期 | 授权已过期，需要重新获取授权码 |
| ❌ 未激活 | 尚未激活，需联系管理员获取授权码 |

点击授权状态可以展开浮层，查看详细信息或清除授权（清除后需重新激活）。

> 授权码与电脑硬件绑定（CPU + 主板 + 网卡），更换电脑后需要重新获取授权码。授权过期后软件会自动弹出激活窗口。

## 常见问题

**Q: 下载失败，提示"未找到知识库 ID"**
A: 请检查 URL 是否正确，确保是知识库地址而不是单篇文档地址。

**Q: 下载失败，提示"知识库目录为空"**
A: 知识库可能需要登录才能访问，请在「认证设置」中填写 Token。

**Q: 部分文档下载失败**
A: 画板类型和数据表类型的文档暂不支持下载，日志中会显示具体的失败原因。

**Q: 预览启动失败**
A: 请确认选择的是包含 .md 文件的知识库目录。如果提示端口占用，服务会自动尝试下一个端口。

**Q: 转换后的 PDF 样式异常**
A: PDF 转换依赖内置浏览器渲染，部分复杂排版可能与原文略有差异。建议降低并发数（设为 1~2）可提高渲染稳定性。

**Q: Word 文件用 WPS 打开格式不正确**
A: 生成的 .doc 文件采用 HTML 格式，推荐使用 Microsoft Word 打开效果最佳。WPS 对部分样式的兼容性可能有差异。

**Q: 换了电脑后软件提示需要重新激活**
A: 授权码与硬件绑定，请将新电脑的机器码发送给管理员获取新的授权码。

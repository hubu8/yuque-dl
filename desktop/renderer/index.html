💡 使用说明：
1. 先在「下载」页下载知识库
2. 选择下载生成的知识库文件夹（包含 .md 文件的目录）
3. 点击「启动预览」，会自动在浏览器中打开预览页面
4. 预览服务会在本地 18888 端口运行，关闭软件时自动停止

快速开始

1
复制知识库地址
打开语雀，进入要下载的知识库，复制浏览器地址栏 URL
格式如：https://www.yuque.com/用户名/知识库名
2
粘贴并选择目录
将 URL 粘贴到「知识库 URL」输入框，点击「选择目录」设置保存位置
3
开始下载
点击「开始下载」，等待完成后点击「打开目录」查看文件

下载私有知识库

如果知识库需要登录才能访问，需要填写 Token：

  1. 在浏览器中登录语雀
  2. 按 F12 打开开发者工具，切换到「应用」(Application) 标签
  3. 左侧找到 Cookie → https://www.yuque.com
  4. 找到 _yuque_session，复制它的值
  5. 在软件中展开「🔐 认证设置」，粘贴到 Token 输入框
💡 企业版语雀的 Cookie 名称可能不同，请在 Cookie Key 中填写实际名称。

常见问题

提示"未找到知识库 ID"

请检查 URL 是否正确，确保是知识库地址而不是单篇文档地址。

提示"知识库目录为空"

知识库可能需要登录才能访问，请在「认证设置」中填写 Token。

部分文档下载失败

画板和数据表类型暂不支持下载，日志中会显示具体失败原因。

换电脑后需要重新激活

授权码与硬件绑定，请将新电脑的机器码发送给管理员获取新授权码。

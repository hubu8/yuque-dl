下载私有知识库

如果知识库需要登录才能访问，需要填写 Token：

  1. 在浏览器中登录语雀
  2. 按 F12 打开开发者工具，切换到「应用」(Application) 标签
  3. 左侧找到 Cookie → https://www.yuque.com
  4. 找到 _yuque_session，复制它的值
  5. 在软件中展开「🔐 认证设置」，粘贴到 Token 输入框
💡 企业版语雀的 Cookie 名称可能不同，请在 Cookie Key 中填写实际名称。

Web 预览

下载完成后，可以通过内置预览服务在浏览器中阅读知识库：

  1. 切换到「🌐 预览」标签页
  2. 点击「选择目录」，选择下载生成的知识库文件夹（包含 index.md 的目录）
  3. 点击「启动预览」，浏览器会自动打开预览页面
  4. 左侧为文件夹树形导航，点击文档名即可阅读
  5. 使用完毕后点击「停止」关闭预览服务，或直接关闭软件会自动停止
💡 预览服务运行在本地 18888 端口，仅本机可访问，不会暴露到网络。

格式转换

将下载的 Markdown 文件批量转换为 PDF 或 Word 格式：

  1. 切换到「🔄 转换」标签页
  2. 选择输出格式：PDF（排版精美，适合分享）或 Word（.doc 格式，可二次编辑）
  3. 选择已下载的知识库目录（包含 .md 文件的文件夹）
  4. 调整并发数：PDF 建议 2~4（需要渲染窗口，占用较多内存），Word 可设更高如 5~10（纯文件写入）
  5. 点击「开始转换」，等待完成
💡 转换结果保存在知识库目录同级的 xxx_pdf 或 xxx_word 文件夹中，目录结构与原始文件保持一致。

常见问题

提示"未找到知识库 ID"

请检查 URL 是否正确，确保是知识库地址而不是单篇文档地址。

提示"知识库目录为空"

知识库可能需要登录才能访问，请在「认证设置」中填写 Token。

部分文档下载失败

画板和数据表类型暂不支持下载，日志中会显示具体失败原因。

预览启动失败

请确认选择的是包含 .md 文件的知识库目录。如果端口 18888 被占用，服务会自动尝试下一个端口。

转换后的 PDF 样式异常

PDF 转换依赖 Electron 内置浏览器渲染，部分复杂排版可能与原文略有差异。建议降低并发数（设为 1~2）可提高渲染稳定性。

Word 文件用 WPS 打开格式不正确

生成的 .doc 文件采用 HTML 格式，推荐使用 Microsoft Word 打开效果最佳。WPS 对部分样式的兼容性可能有差异。

授权过期了怎么办

授权过期后会自动弹出激活窗口，请将机器码发送给管理员，获取新的授权码后重新输入激活即可。
